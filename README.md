# مصنع التطبيقات (AI App Factory)

تطبيق Flutter يعمل على الهاتف: تكتب فكرة تطبيق، فيولّد الذكاء الاصطناعي مشروع Flutter كاملاً، ويفحصه، ويضغطه في ملف ZIP، ثم (اختيارياً) يبني ملف APK عبر GitHub Actions وينزّله إلى هاتفك.

## كيف تحصل على ملف APK لهذا التطبيق نفسه

لا يحتاج جهازك إلى Flutter. يُبنى الـ APK على GitHub:

1. أنشئ مستودعاً جديداً على GitHub (خاصاً أو عاماً).
2. فك ضغط هذا الـ ZIP وارفع كل محتوياته إلى المستودع (الفرع `main`).
   - من الموقع: Add file ← Upload files، واسحب الملفات والمجلدات كلها.
   - تأكد أن المجلد المخفي `.github` رُفع أيضاً، لأنه يحتوي ملف البناء.
3. افتح تبويب **Actions** وانتظر انتهاء `Build Flutter APK` (عدة دقائق).
   - إن لم يبدأ تلقائياً: اختر الـ workflow ثم Run workflow.
4. من صفحة التشغيل المكتمل، نزّل الملف من قسم **Artifacts** باسم `apk`.
5. فك ضغطه، وانقل `app-release.apk` إلى هاتفك وثبّته (اسمح بالتثبيت من مصادر غير معروفة).

> الـ APK موقَّع بمفتاح debug، وهو مناسب للتجربة الشخصية. للنشر على Google Play يلزم إعداد مفتاح توقيع.

## استخدام التطبيق

داخل التطبيق شاشتان مساعدتان:

- **الإعدادات**: مزوّد الذكاء الاصطناعي (Anthropic / Gemini / OpenRouter) ومفتاحه واسم النموذج، ورمز GitHub، والإعدادات المتقدمة (حد الرموز، محاولات الإصلاح).
- **دليل الاستخدام**: شرح مفصّل لكل خطوة وحل المشاكل الشائعة.

باختصار: أدخل المفتاح في الإعدادات، اكتب الفكرة، واضغط "ابدأ التوليد".

### رمز GitHub

مطلوب فقط لبناء APK. أنشئ **Personal access token (classic)** من `github.com/settings/tokens` بصلاحيتي `repo` و`workflow`. الرمز الدقيق (fine-grained) لا يستطيع إنشاء مستودعات جديدة لحسابك الشخصي.

## بنية المشروع

```
lib/
├── main.dart
├── core/            الثيم والأخطاء
├── models/          إعدادات التطبيق
├── providers/       متحكمات الحالة (provider)
├── screens/         الرئيسية، الإعدادات، الدليل
└── services/
    ├── llm_client.dart         Anthropic / Gemini / OpenRouter
    ├── prompts.dart            تعليمات النموذج
    ├── response_parser.dart    تحويل رد النموذج إلى ملفات
    ├── project_validator.dart  فحص ثابت قبل البناء
    ├── project_packager.dart   تنظيف، حقن ملف CI، ZIP
    ├── github_builder.dart     مستودع، رفع، بناء، تنزيل APK
    └── factory_pipeline.dart   ربط كل المراحل مع الإصلاح التلقائي
test/                اختبارات الوحدات
.github/workflows/   بناء الـ APK
```

## ملاحظات

- المفاتيح تُحفظ في مساحة التطبيق الخاصة على الهاتف ولا تُرسل إلا إلى المزوّد وGitHub.
- ملف الـ workflow يمرّ على `flutter analyze` و`flutter test` قبل البناء. في هذا المشروع نفسه خطوة الاختبار لا توقف البناء (`continue-on-error`)، أما المشاريع التي يولّدها المصنع فاختباراتها إلزامية.
- النسخة الحالية تستهدف أندرويد. نسخة الويب لاحقاً ستستبدل طبقتي حفظ الملفات والمشاركة فقط، وستحتاج معالجة قيود CORS في تنزيل ملف البناء من GitHub.
